# Elena Maksimova-Khalipovskaia — QA Engineer

Personal portfolio website: https://elenakhalipovskaia.github.io/

A static one-page site built with plain HTML and CSS.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page content: intro, about, experience, skills, contacts |
| `style.css` | All styles: colors, fonts, layout, mobile version |
| `normalize.css` | Resets browser default styles |
| `avatar.jpg` | Profile photo |
| `Elena-Maksimova-Khalipovskaia-CV.pdf` | CV available for download |

## How to update

- **Photo:** replace `avatar.jpg` with a new image using the same file name. Portrait orientation (about 4:5) works best.
- **CV:** replace `Elena-Maksimova-Khalipovskaia-CV.pdf` with a new PDF using the same file name.
- **Colors:** change the values at the top of `style.css` (the `:root` block).
